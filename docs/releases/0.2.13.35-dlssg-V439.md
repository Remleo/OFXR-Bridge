# OFXR Bridge V439, release 35

This release adds clearer DLSS diagnostics, an optical-flow-only fallback,
and controls on the hand opposite the options panel.

## Changes

- **Hold the left controller upside down; select with the right.** The
  right thumbstick navigates and changes options, and holding the right
  trigger applies them. Opening the panel on the right controller uses
  the left controller's controls instead.
- **DLSS warnings explain what happened.** Repeated DLSS evaluations now
  report no new frame data separately from invalid guides or broken frame
  history. Help text explains that menus and loading screens can pause DLSS.
  Size mismatches show the latest DLSS output and requested eye-image sizes.
- **Optical flow only.** Select **Method: OFXR**, then **Mode: optical flow
  only** in the headset, or its entry under **Frame generation method** in
  the tray. This bypasses game motion vectors when they cause artifacts,
  without requiring FoV changes. The setting survives restarts and stays
  synchronized between the headset and tray. Switching back to interpolate
  or hybrid enables game vectors again. Native DLSS Frame Generation still
  requires game guides.
- **Clearer vector statistics.** The panel says how many checked pairs
  accepted the guides. Acceptance does not establish that the motion field
  is visually correct for the displayed eye.
- **Alternating-eye history.** Array swapchains now retain the intervening
  raw DLSS evaluation needed by the existing conditional cross-eye motion
  correction, matching the separate-eye swapchain path.

## Using the fallback

Interpolation modes can switch live from the headset. Entering or leaving
extrapolation still requires a game restart. Tray changes take effect at the
next game start. For missing vectors, first check gameplay with DLSS upscaling
enabled; menus may stop publishing the guides even when racing works.

The Control artifact report still needs a game capture to verify its cause
and the visual effect of the history correction. This release does not claim
to fix every VR mod's motion-vector convention.

## Validation and package

Targeted checks cover panel/controller behavior, settings persistence,
benchmark labels, the public API, and D3D12 guide pairing and correction.
The Windows x64 archive includes the tray app, OpenXR and Vulkan layers,
benchmark, production NVIDIA DLSS-G runtime, documentation, and licenses.
`SHA256SUMS.txt` lists the packaged files' checksums.

Disable OFXR and close games using it before replacing an existing install.
Extract the archive and run `OFXRBridgeTray.exe` to enable it again.
